# Artist Roadmap Template (Milestone-based, phase-aware)

Each milestone has: goal · owner sub-agent · deadline · status · blocker.

## Phase 0 — PreD (is this worth doing?)
- [ ] Problem/opportunity stated in one sentence
- [ ] 3 alternatives considered and rejected
- [ ] Success criteria defined (measurable)

## Phase 1 — Design (what exactly are we building?)
- [ ] Business plan drafted (see business-plan-template.md)
- [ ] Brand brief (Brand Manager)
- [ ] Banking/entity plan (Finance + Legal)

## Phase 2 — Build (do it)
- [ ] Catalogue imported + registered (Publishing)
- [ ] EPK + website (Brand)
- [ ] Release campaign plan (PR)
- [ ] Booking CRM seeded (Booking)

## Phase 3 — Launch (ship it)
- [ ] First release live + pitch emails sent (PR)
- [ ] Gigs booked (Booking)
- [ ] Royalty dashboards live (Publishing)

## Phase 4 — Iterate (what's working?)
- [ ] Monthly P&L (Finance)
- [ ] Campaign ROI review (PR)
- [ ] Roadmap re-plan + status report

## Cadence
- Weekly status: blockers + wins
- Monthly digest: artist-facing summary
